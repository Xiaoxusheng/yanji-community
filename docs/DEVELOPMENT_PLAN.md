**验收标准（阶段 1 全部满足）**：
1. 游客可浏览，互动接口 401。
2. 注册→验证→登录→发帖→评论→点赞→收藏→关注→通知 全链路可用。
3. 越权编辑/删除他人内容 403；重复点赞/关注/收藏不重复计数（DB 唯一约束）。
4. 锁定帖评论 409 POST_LOCKED；hidden/deleted 不进公开流与搜索。
5. 版主跨版块操作 403；管理员操作写审计。
6. 举报→后台处理全状态留痕。
7. 列表分页/索引/空错载状态齐备。

## 已知限制与决策记录

1. **DB 访问采用 pgx 直写 SQL**，sqlc 生成列为后续优化（决策：无 sqlc CLI 环境，薄 repo 层已保证类型安全）。
2. **Markdown 编辑器为自建 textarea + 工具栏 + 净化预览**（goldmark 服务端渲染），Milkdown 等富编辑器列为后续增强；服务端净化为唯一信任边界。
3. **Outbox 消费为 API 进程内嵌 dispatcher + 独立 worker 二进制**，1s 轮询；Redis Stream 队列列为后续。
4. **浏览量**用 Redis SETNX 去重（1h 窗口），精确 UV 明细表列为后续。
5. **验证码/人机校验**未接入（注册/登录仅限流），hCaptcha/Turnstile 列为阶段 2。
6. 本机无 Docker/PostgreSQL：集成测试在无 `TEST_DATABASE_URL` 时自动 SKIP；端到端运行验证需 `docker compose up`。
