# PRD — 综合社区论坛平台（产品需求文档）

> 版本：1.0 ｜ 状态：阶段 1（核心 MVP）实施基线
> 本文档是产品需求基线，与 `DEVELOPMENT_PLAN.md` 的阶段划分对应。

## 1. 产品定位

面向广泛兴趣主题的**开放注册综合社区论坛**。核心内容模型为「主题帖 + 评论/楼中楼」，兼容讨论帖与长文章（问答帖、投票帖为第二阶段）。游客可浏览公开内容；注册用户可发帖、评论、点赞、收藏、关注、举报，并拥有个人主页与通知中心；管理端提供用户/内容/版块/举报/RBAC/运营配置/审计能力。

## 2. 用户角色

| 角色 | 主要能力 | 关键限制 |
|---|---|---|
| 游客 | 浏览公开首页/版块/帖子、搜索 | 不能发帖、评论、点赞、收藏、关注 |
| 注册用户（未验证邮箱） | 浏览、登录、修改资料 | 默认禁止发帖/评论（可配置），不能互动 |
| 注册用户（已验证邮箱） | 完整互动：发帖/评论/点赞/收藏/关注/举报 | 受版块规则、频控约束 |
| 版主 | 管理授权版块的帖子/评论/举报 | 不能越权管理未授权版块或全站账号 |
| 内容审核员 | 审核内容、处理举报 | 不默认拥有角色/系统配置权限 |
| 管理员 | 管理用户、内容、版块、配置 | 敏感权限按 RBAC 单独授权 |
| 超级管理员 | 角色权限、全站设置 | 高危操作写审计日志 |

权限一律在 Go 服务端校验；前端隐藏按钮仅是体验优化。

## 4. 功能需求（阶段 1）

### 4.1 账号（模块 A）
- 公开注册：用户名（3–20，字母数字下划线，唯一）+ 邮箱（唯一）+ 密码（≥8，Argon2id 存储）。
- 登录/登出/全部登出；会话 Cookie `HttpOnly + SameSite=Lax`，生产 `Secure`；DB 存 token 摘要。
- 邮箱验证：一次性 token（DB 存摘要，24h 过期）；未验证用户按配置禁止发帖/评论。
- 密码重置：一次性 token（30 分钟），重置成功后撤销全部会话。
- 会话设备管理：列表、撤销单个、撤销全部。
- 防枚举：注册/找回密码返回统一模糊提示；登录失败限流。

### 4.2 内容（模块 B）
- 帖子类型：`discussion`、`article`（`question`/`poll` 数据模型预留、入口标记「规划中」）。
- 状态机：`draft → pending_review → published →(rejected/hidden/locked/deleted)`，服务端统一控制。
- 发帖必选版块，标签 0–5 个；标题 5–120 字；正文 Markdown（渲染经净化）。
- 草稿保存/继续编辑/删除；发布受版块 `posting_policy`/`review_policy` 控制。
- 编辑保留修订历史（post_revisions）；作者删除为软删除。
- 首页四种流：latest（published_at）、hot（热度分）、featured（is_featured）、following（关注聚合）；推荐=recommended（热度+时效规则排序）。
- 版主/管理员可置顶、加精、锁定、隐藏、恢复、移动版块。

### 4.3 讨论（模块 C）
- 一级评论 + 楼中楼，最大嵌套深度 3；超过深度自动转为对父级评论的引用回复。
- 评论支持 Markdown 子集渲染（净化）；@提及生成通知。
- 评论点赞、编辑（作者本人）、删除（作者本人/版主/管理员，软删除保留占位）。
- 锁定帖禁止新评论（`POST_LOCKED`）。

### 4.4 互动（模块 D）
- 帖子点赞/取消、评论点赞/取消：DB 唯一约束防重，幂等。
- 收藏：默认收藏夹 + 自定义收藏夹；`bookmarks(user_id, post_id)` 唯一。
- 关注用户/版块/标签；拉黑用户（拉黑后双向内容流过滤）。

### 4.5 搜索（模块 E）
- PostgreSQL 全文检索：帖子标题+正文（tsvector）、用户名/昵称（trigram/ILIKE 前缀）、版块、标签。
- 筛选：类型/版块/标签/作者/时间范围；排序：相关度/最新/热门；关键词 `<mark>` 高亮。
- 公开内容限定 `status='published'` 且版块可见。

### 4.6 通知（模块 F）
- 类型：comment、reply、mention、like_post、like_comment、follow、moderation、system。
- 触发经 Outbox 事件异步落库（事务提交后投递，失败重试）。
- 未读数、分页列表、单条/全部已读、删除、通知偏好。

### 4.7 治理（模块 G）
- 敏感词：命中 `block` 拒绝发布 / `review` 转待审核。
- 举报：帖子/评论/用户，原因枚举，同用户同对象去重；后台分派/处理/驳回全留痕。
- 处罚：警告/禁言/禁止发帖/临时封禁/永久封禁；后端统一判定生效状态（查询时判定 + 过期自动解除）。
- 审核队列：`pending_review` 帖子通过/驳回（原因必填）。

### 4.8 后台（模块 H）
- 仪表盘：用户/帖子/评论总量与今日新增、待审核数、待处理举报数。
- 用户管理：列表筛选、详情、封禁/解封（写审计）。
- 内容管理：帖子/评论全状态列表、审核、批量隐藏。
- 版块/标签/公告管理；RBAC 角色与权限点管理；系统配置（site_name 等公开配置）。
- 审计日志：管理员关键操作全记录（操作者/动作/目标/IP/request_id），不可删除。

## 5. 关键业务规则

1. 游客可浏览公开内容，不能互动（401）。
2. 未验证邮箱默认禁止发帖/评论（`EMAIL_NOT_VERIFIED`）。
3. 用户只能编辑/删除自己的帖子/评论（对象级校验）。
4. 版主只能管理授权版块（user_roles scope 绑定 category_id）。
5. `locked` 帖禁止新评论；`hidden/deleted` 内容不出现在公开列表、搜索、推荐。
6. 评论树最大深度 3。
7. Markdown 渲染必须净化（bluemonday 白名单），禁止任意 HTML/脚本。
8. 上传校验 MIME 白名单 + 扩展名 + 实际文件头（magic number）+ 大小；随机存储名。
9. 密码 Argon2id；会话 Cookie HttpOnly/Secure/SameSite；localStorage 不存长期凭证。
10. 重要操作写 operation_logs。
11. 通知/邮件走 Outbox 可靠异步。
12. 计数原子更新（`UPDATE ... SET x = x + 1`），提供校准接口。
13. 所有接口参数校验 + 认证 + 对象级权限 + 限流。
14. 帖子创建/编辑支持 `Idempotency-Key` 请求去重（Redis 8h TTL）。

## 6. 非阶段 1 范围（明确标记「规划中」）

积分等级勋章、签到、问答最佳回答、投票、活动、SSE、申诉、私信、WebSocket、知识库/AI、商业化。

## 7. 验收演示链路（阶段 1）

注册 → 验证邮箱 → 登录 → 浏览版块 → 发帖 → 详情 → 评论（楼中楼）→ 点赞/收藏 → 作者收通知 → 举报评论 → 管理员后台处理举报/审核帖子 → 全程审计可查。
